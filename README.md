# Bank Account System

A Java console application designed to practice Object-Oriented Programming (OOP) concepts such as classes, objects, encapsulation, and methods.

## 🚀 Features
* **Create Account:** Register new accounts with basic details.
* **Deposit Funds:** Add money securely to an existing balance.
* **Withdraw Funds:** Deduct balance with validation for overdrafts/insufficient funds.
* **Check Balance:** Display current account summary.

## 🛠️ Concepts Applied
* **Classes & Objects:** Modeled bank accounts and customer interactions as reusable class instances.
* **Encapsulation:** Protected sensitive fields (like `balance` and `accountNumber`) using private modifiers and public getters/setters.
* **Methods & Parameters:** Structured business logic into clean, reusable methods for depositing, withdrawing, and displaying account details.

## 🧰 Tech Stack
* **Language:** Java (JDK 17+)
* **Interface:** Command Line / Console
